# Sürü Trafiği – Web Sürümü

Bu depo yalnızca oyunun derlenmiş WebGL sürümünü içerir (kaynak kod gizli depodadır).

Oyna: https://samet3474.github.io/SuruTrafigi-Web/

İlk oynanabilir sürüm (Orman dünyası, 20 bölüm): hayvanlara dokun, baktıkları yöne koşup bekleme alanına
gitsinler. Aynı türden 3 hayvan buluşunca kurtarılır; 5 yuvalık bekleme alanı üçlü oluşmadan dolarsa bölüm biter.
Önü kapalı hayvana dokunmak hata sayılır (0-1 hata 3 yıldız, 2-3 hata 2 yıldız, 4+ hata 1 yıldız).
İlerleme ve ayarlar tarayıcıda saklanır. Telefonda tam ekran, masaüstünde dikey çerçeve olarak açılır.

Önceki görsel prototip: https://samet3474.github.io/SuruTrafigi-Web/gorsel-test/

Hayvanlar, doğa ve sesler: Kenney (kenney.nl, CC0). Yazı tipi: Baloo 2 (SIL OFL 1.1). Müzik: özgün.
