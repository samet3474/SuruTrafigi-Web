# Sürü Trafiği – Web Test Sürümü

Bu depo yalnızca oyunun derlenmiş WebGL sürümünü içerir (kaynak kod gizli depodadır).

Oyna: https://samet3474.github.io/SuruTrafigi-Web/

Prototip (Aşama 4, Kenney görselleri): hayvanlara dokun, ok yönüne gitsinler. Yolu kapalı hayvan "hayır" hareketi yapar ve yerinde kalır. Çıkan hayvan alttaki 5 slotlu bekleme alanına geçer; aynı yaşam alanından 3 hayvan (orman: tavşan, geyik, tilki; buz: penguen, kutup ayısı; savan: aslan, fil, zürafa) toplanınca dans edip kurtarılır. Bekleme alanı doluysa yeni hayvan çıkmaz. Takılırsan sayfayı yenile. Telefonda tam ekran, masaüstünde dikey çerçeve olarak açılır.

Görseller: Kenney Cube Pets ve Nature Kit (kenney.nl, CC0).
