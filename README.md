# Sürü Trafiği – Web Test Sürümü

Bu depo yalnızca oyunun derlenmiş WebGL sürümünü içerir (kaynak kod gizli depodadır).

Oyna: https://samet3474.github.io/SuruTrafigi-Web/

Prototip (Aşama 4): hayvanlara dokun, ok yönüne gitsinler. Çıkan hayvan alttaki 5 slotlu bekleme alanına geçer; aynı yaşam alanından (aynı renk) 3 hayvan toplanınca kurtarılır. Bekleme alanı doluysa yeni hayvan çıkmaz. Takılırsan sayfayı yenile.
